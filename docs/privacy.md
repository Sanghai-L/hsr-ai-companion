# 本地资料与外部请求

账号快照、研究、实验和确认记录保存在玩家指定的数据目录。普通使用不会向开发者上传这些内容；本项目没有遥测、账号平台或后台模型服务。宿主模型可能读取你在当前对话或工具结果中提供的资料，其数据政策由你使用的宿主与渠道决定。

明确导入／刷新公开 UID 时，请求发送到 enka.network，URL 中包含该 UID。启动、资料 TTL 到期、知识同步与计算均不会自动刷新 UID。公开来源获取只请求所选来源；维护者发布检查访问本机配置的发布域。网络传输只用 HTTPS，拒绝自动跳转、内网解析及凭据 URL，不使用系统代理转发。

本地网络诊断只记录目的域、操作类型、时间、HTTP 状态与结果，不记录完整 URL、UID、请求头、正文和凭据，最多保留 500 个事件。诊断分享先用 `diagnostics-plan` 生成待审阅文件清单；看过文件后再用 `diagnostics-export` 导出到本地。工具不会自行上传。默认报告排除账号 ID、快照、私人研究、外部资料正文、配置和本地路径。

程序卸载默认保留个人数据。独立选择 `--purge-data` 会把个人目录改名到隔离位置，便于误操作恢复；确需永久删除时由玩家自行删除隔离目录和安装备份。安装备份可能含个人数据库，应按私人资料保护，不能随公开发布物分享。
