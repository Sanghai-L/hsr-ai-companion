# 更新、确认与信任边界

公共知识仅含数据，兼容更新自动校验后生效，默认六小时检查。完整代与索引准备好后才原子切换指针，保留上一有效代。断网、损坏、不兼容和未配置来源时不宣称最新。运行时只读本机配置的维护者来源；HTTPS拒绝重定向、内网解析与凭据地址，采用有大小预算的传输。

P6索引及内容清单用Ed25519签名，本机预先固定公钥；正式路径拒绝测试身份。初装可合并签名包绑定的来源，保留已有玩家配置和备份。知识同步不能写代码、规则、Skill、程序配置或账号资料。单独的开发测试源保留原离线fixture格式，不用于正式配置。

程序检测与生成方案不会安装。方案绑定目标版本、SHA-256、范围、路径及唯一ID；版本、包或作用范围变化后旧批准无效。program_update_apply要求匹配的一次性确认，实际暂存、备份、候选数据库迁移和自检通过后才切换不可变版本；失败恢复日志保留旧可用版本，运行中的依赖不被覆盖。卸载默认保留个人目录，清理资料为独立显式选择。

MCP没有确认写入API，不接受confirmed=true、模型编造引用或宿主状态作为批准。record_verified只供可信适配器提供独立验证函数；当前Codex业务确认采用本地交互终端confirm-update，玩家阅读完整方案后输入绑定短语，管道或非TTY拒绝记录。同一有效方案已有确认时直接消费，不重复询问。

本策略不防御同一OS用户下可直接改SQLite、代码或公钥文件的恶意进程。宿主原生权限与模型参数分离。更新器不刷新UID，不向维护者上传账号或研究。恢复命令、签名与隐私细节见../release/signing.md、../troubleshooting.md和../privacy.md。
