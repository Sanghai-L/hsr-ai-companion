# 私有存储合同

每个安装实例用指定 data-dir 下的 personal/ 保存 SQLite 与不可变研究正文；账号、快照、字段来源、偏好、研究、冲突、实验、操作记录和更新确认均有初始迁移。外键采用账号与对象复合键，查询显式指定账号。SQLite 使用事务、10 秒忙等待、FULL 同步；异常回滚，并发写由数据库串行提交。

研究正文先写入含 ID、账号和元数据的 Markdown 文件并 fsync，再事务登记索引。正文不可覆盖；崩溃后的孤立文件可在本地恢复，损坏／丢失记录明确报告，不自动删除。文件与索引通过 SHA-256 核对。操作记录避免保存 UID 等原始个人字段。

路径必须在指定根内，拒绝绝对路径、..、ADS、Windows 保留名称及符号链接／reparse point／junction。每次读写重新检查祖先；运行时 public knowledge/ 与 personal/ 分开。此检查防止误配置与包路径逃逸；不声称能隔离同一用户恶意并发替换目录的全部 OS 竞态。程序不提供任意路径写入工具。
