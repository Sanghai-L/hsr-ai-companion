# 战斗模拟合同

> 2026-11-08：产品目标已改为 [简化战斗比较](../decisions/ADR-007-simplified-combat-scope.md)。**下文描述目前已实现接口，代码本次未变。** 新的代表性场景和按方法预检尚待 D038 实施；不要把文档修订理解为现有预检已放宽或比较接口已开放。完整 AI／阶段／人工整场校准不再是新范围的通用开发门槛，原 high 精度声明仍须对应证据。

P4 使用固定 commit 的 HSR_Nous 纯模拟核心，主程序不导入它的依赖。安装时在玩家数据目录放置 `simulator-runtime.json`，明确指定 `python`、`repository`、`data`、`generated_templates` 四个本机绝对路径；所有运行前按程序包内 `manifests/simulator.lock.json` 校验代码、规则、模板和所用数据。不会自动下载、更新或登录；解释器以隔离模式运行，禁止核心联网和另起进程。

公共知识同步不能携带代码、模板 DSL 或本机运行时配置。模拟器变更属于程序／执行规则更新。结构化桥接返回快照、事件、伤害样本、caveats、Python 告警、终止原因及实际后端／补丁指纹，不解析控制台文字取得业务数值。

`compile` 与 `execute` 是安装层接口。玩家工具只接受经过合同验证的构筑和场景 ID，不能上传原始 DSL、模板路径或执行文件。未配置运行时返回具体缺项；完整性失败拒绝执行，不能静默切换到在线服务或上游 main。

当前首个冻结场景是历史 4.4.1／1034／12 层上半，不能自动当作当前关卡。模型内复现与客户端校准分别记录；仅有可运行输出不足以声明完整支持、通关预测或队伍投资排名。

`simulation_schema` 返回原严格后端的实验／构筑合同与原创示例；`simulation_preflight` 返回机制状态、证据、影响、覆盖指纹和资格。`model_diagnostic` 只检查不完整工程模型能否执行；`high` 在关键机制或校准缺失时拒绝。完整后端的提交及任务控制未开放；当前简化比较、保存与重算另见 representative-analysis.md。

`simulation_build_import` 只读本地账号快照，返回独立草稿、最小补充字段和问题。不默认毕业练度，不把未列出装备当作无装备。手工补充必须带来源；假设必须写明条件，“如果抽到”仍保留原始持有状态，不修改账号。`simulation_build_validate` 检查同一角色／形态和装备实例占用、命途、遗器槽位与词条等约束。

展示面板只用于校对，绝不作为白值再次叠加装备；精确遗器词条按明确数值绑定，不反推虚构的强化次数。技能等级是星魂加成前的等级，后端负责加算；不直接把展示等级重复加 E3／E5。形态未知不能落到默认模板。

当前模板绑定只支持已登记的八名候选、80级满突破、全行迹。低等级／突破、部分行迹及白值覆盖返回具体未支持项，不将标签改成合法数值后执行。身份目录中的光锥／套装存在不等于其触发机制已核验，仍须覆盖预检。

速度精度为 0 表示输入明确给出精确值；正精度但舍入方式不明时给显示值±一个单位的保守区间；精度未知时上下界也标未知，要求精确值或独立舍入假设，不能编造有限范围。账号中比例／百分点转换保留来源和精度。

原后端的有界修复已将关卡指定的hard／elite数值与元素抗性传入真实编译对象，原模板和P0输入保持。引擎battle_end原因与安全截断分别标记胜利／全灭／超时／不完整；上半结果不推导整层星数。完整敌人AI与阶段未补齐，属于可选旧后端限制。D038～D049已按简化范围通过，当前默认路线不要求复刻完整战斗。
