# 计算与模式覆盖

2026-11-08；简化方法 `representative-1`。正式阶段状态见[任务账本](development/task-status.md)和[P5关口](gates/P5-beta.md)。

| 模式 | 已实现的代表性比较 | 仍为定性／未建模 |
|---|---|---|
| 混沌回忆 | 同一目标模型、AV窗口、初始资源下的两队指定动作输出／收支；保存与重算 | 真实波次、敌人AI、生存与精确轮次 |
| 虚构叙事 | 固定密度、显式补怪假设与跨50%血线机会；群攻／单体取舍 | 真实击杀、狂热、补怪状态机与分数 |
| 末日幻影 | 两个外部击破窗口的直伤、弱点匹配削韧容量及资源准备 | 自动破韧、锁韧AI、击破／超击破伤害、Boss完整阶段与得分 |
| 异相仲裁 | 单骑士代表性配置；三骑士与可复用王棋的候选分配／冲突检查 | 当期特性、裁决象限收益、生存、王棋星数和评分 |

丹恒与黑塔提供有来源的机制差异：单体技能倍率与全体目标／血线触发，目标数可以改变选择。另10名角色只覆盖限定条件下的普攻资源位；这不等于12名完整角色或四类完整战斗体系。当前E0、指定技能等级且无大行迹；未验证动作、核心机制或数据版本返回缺项。

多队来源是明确假设可用清单；不把UID未展示当未持有。角色不同形态共享占用，装备按实例区分。建议只针对给定候选；未穷举完不声称最优，无合法解不返回非法高收益队伍。

当前条件连接器支持正式服混沌／虚构／末日索引，冻结日期、内容哈希与所用参数；没有明确区服有效排期时不确认“当前”。异相尚无当前期数连接器。离线、格式变化和证据不足均有降级测试，不妨碍明确范围的通用比较。

P0～P3既有功能和严格后端预检保留。完整战斗准确性、当前新角色全机制、真实配队的自动最优策略及任意账号收益排名均未宣称支持。
