# 排障与恢复

先让 Agent 查询 local_help。已安装程序在项目自己的运行时中，未必有全局 companion 命令；管理安装、恢复、回滚和卸载时，优先从候选介质调用 Install-HSR.ps1，它会选择自带运行时。不要在占用该安装的会话中删除自身程序。

| 现象 | 处理 |
|---|---|
| MCP没有加载或项目未受信任 | 使用玩家项目的 .hsr-companion/打开助手.ps1；该入口使用会话级配置，不修改全局信任。核对 Codex 已登录及已测版本。 |
| 缺角色／装备／保底 | 读取 missing_fields；补关键资料，或明确接受合成假设。不用未展示推断未持有。 |
| 离线、限流或来源不可用 | 读取带日期缓存并说明时效，保持已有资料，不切换未知代理或自动刷新UID。 |
| 更新源 unconfigured | 尚未配置维护者来源，不能宣称最新；初装介质可提供签名绑定来源，已有自定义配置保持不变。 |
| 包损坏、未知签名者或TEST包被拒 | 停止安装，从已认可的维护者渠道取得匹配介质／公钥，不用包内自报公钥取得信任。 |
| 升级中断／迁移失败 | 保留旧目录，退出占用会话后运行 Install-HSR.ps1 -Workspace <项目> -Action recover。不要强删锁文件。 |
| 新版不适用 | 使用同一介质的 -Action rollback；先验证旧程序完整性与当前数据库兼容性，保留新研究，不直接还原陈旧私人备份。 |
| 程序正在使用，卸载被拒 | 退出占用该安装的会话，再从外部候选介质卸载。 |
| 旧实验提示版本不兼容 | 有精确匹配且签名有效的受管旧快照时可重算；缺原快照或快照损坏就保留历史，不能静默换新规则。 |
| 研究冲突未处理 | 查看具体方案，玩家确认后在本地终端记录一次确认；没有回复不会覆盖旧文。 |
| 参数不符合合同 | 定量问题先 calculation_schema／analysis_schema；分页遵守返回上限，不生成临时计算脚本代替工具。 |

程序确认用 `confirm-update --plan <方案ID>`；研究修订用 `confirm-revision --account <账号> --plan <方案ID>`，均需本地交互终端。管道、confirmed=true 或编造确认编号无效。

排障分享先执行 diagnostics-plan，审阅返回的 share-plan.json 与 diagnostics.json，再用 diagnostics-export --plan <清单> --output <新的zip> 导出本地文件。默认内容和隐私边界见 privacy.md；不会自动上传。
