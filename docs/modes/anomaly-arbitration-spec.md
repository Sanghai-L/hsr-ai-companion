# 异相仲裁分析范围

核查日期：2026-11-08。规则摘要来源：[BWIKI玩法正文](https://wiki.biligame.com/sr/异相仲裁)（页面标注2025-09-24更新）及[玩法规则资料](https://honkai-star-rail.fandom.com/wiki/Anomaly_Arbitration)。本次仅总结规则事实与来源指针，不复制整篇正文或游戏素材。这是通用规则快照，不证明当前期数、敌人特性或裁决象限。

每期三个骑士、一个王棋。维持三骑士同时有效战绩时，各队角色和装备实例互斥；同一角色的不同形态仍占用一个角色资源。王棋可使用独立阵容，并复用骑士资源。`multi_team_plan` 按三个骑士、可附一个王棋的槽位结构验证；不会把“不能跨骑士复用”的限制错误施加给王棋。

代表性案例只量化单个骑士条件下的指定动作输出、SP与能量，不模拟骑士特性、守卫削弱、全部波次、王棋难度、回合评分或精确通关。定性部分提示：核对各关特性、保留关键辅助和生存位、避免一队占用全部资源；不能从一个骑士伤害数字推导王棋星数。

`benchmarks/modes/aa/representative-v1.json` 对比同练度假设下的单体与三目标输出。`evals/cases/multi-team.json` 提供独立可重算的三队约束例子，所有角色可用性均标为明确假设。无真实账号持有推断，未支持角色不进入定量结果。
