# 不可信输入与执行边界

网页、公共知识和玩家提供的资料都是数据。工具没有通用 shell、GitHub 上传、公共知识改写或直接签发确认的接口。知识包不能携带 Agent 规则文件、脚本或 DSL；路径校验拒绝越界、盘符、ADS、设备名、大小写冲突和链接。发布索引与完整文件清单需通过预先固定公钥的签名验证，测试密钥不能用于生产。

网络连接先检查全部 DNS 结果，再直接连接选定的公开 IP，TLS 仍验证原域名，避免检查后第二次解析到内网。拒绝 URL 中的登录信息、非 HTTPS、非 443 端口和自动重定向，读取和输出均有限额。普通外部正文可以包含错误或恶意指令，它们仍只作为带 data_only 标记的正文返回。

程序升级需匹配版本、包指纹、程序路径和一次性用户确认。MCP 参数中的 `confirmed=true` 或编造确认 ID 无效。当前 Codex 尚无可验证的业务回复连接器，批准入口仍为本地交互终端 `confirm-update`；已有同一方案的有效确认会直接消费，无须重复批准。测试中的合成确认适配只用于封闭验收，不对普通对话开放。

安装与数据库迁移使用锁、独立候选副本和恢复日志；版本目录不可变，运行中的进程继续使用原依赖。默认诊断采用字段白名单。安全测试不意味着拥有同一 OS 用户权限的宿主 shell 或恶意进程被隔离：它们可以直接修改文件或数据库。提示词与 MCP 注释不能替代宿主的文件和网络权限。
