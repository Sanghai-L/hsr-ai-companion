# 同名角色的形态与实体 ID

同名或同一人物的不同战斗形态使用不同实体 ID，例如三月七存护与巡猎、丹恒与饮月及腾荒。读取账号、技能和研究时应保留形态标识。

适用范围：4.6 锁定资料；正式服文本核对，不等于游戏实测。

例外与待核实：拥有一个形态不能自动推断另一形态的练度与装备。
