# 首个混沌场景的证据边界

固定目标仍是 `alpha-moc`，历史 4.4.1／1034／12层上半；原快照及第三方原始资料只保存在 `.local`，共享目录不重新分发游戏数据。

`tests/modes/test_moc.py` 包含独立手算的合成属性基准：HP=10×2×5×1.5=150，ATK=5×3×2=30，DEF=3×4=12，SPD=100×1.1+2+3=115。它核对关卡系数和单位转换，不是游戏内校准。

场景适配器已经将关卡指定的等级／精英组与元素抗性传给真实编译对象；两波敌人都有来源指纹。它仍拒绝编译为完整关卡，因为三种敌人的行为与阶段没有完整执行。只允许开发验证显式请求不完整模型诊断；这不开放为玩家模拟提交或比较工具。

全灭、超时、引擎安全截断均与胜利区分。上半结果不能推导整层星数。完整首轮／转波／击破／阶段逐事件验证及外部校准尚未通过。
